# _База данных пункта проката автомобилей_
## О проекте

База хранит информацию о клиентах, автомобилях, пунктах проката, договорах аренды и бронированиях.
клиенты и сотрудники (менеджеры, админы) хранятся в одной таблице `client`, а их роль определяется через справочник `role`.

## Структура базы

### Таблицы

| таблица | назначение |
|---|---|
| `role` | роли пользователей: клиент, менеджер, админ |
| `client` | клиенты и сотрудники (фио, телефон, дата рождения, роль) |
| `rental_point` | пункты проката (город, адрес, вместимость, закреплённый менеджер) |
| `car` | автомобили (vin, марка, год, пробег, текущий пункт) |
| `contract_status` | справочник статусов договора (черновик, активен, закрыт, отменён) |
| `rental_contract` | договоры аренды (машина, пункт выдачи/возврата, даты, статус) |
| `booking` | бронирования (клиент + договор) |

### Связи

- `role` → `client`: одна роль у многих клиентов (`role_id`)
- `client` → `rental_point`: за пунктом закреплён менеджер (`manager_id`)
- `rental_point` → `car`: в пункте много машин (`rental_point_id`)
- `car` → `rental_contract`: у машины может быть несколько договоров (`car_vin`)
- `rental_point` → `rental_contract`: пункт выдачи и пункт возврата (`pickup_point_id`, `return_point_id`)
- `contract_status` → `rental_contract`: у договора один статус (`status_id`)
- `client` → `booking`: клиент делает бронь (`client_id`)
- `rental_contract` → `booking`: бронь привязана к договору (`contract_id`)
